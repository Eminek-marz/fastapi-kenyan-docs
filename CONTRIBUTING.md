# Mwongozo wa Kuchangia (Contributing Guidelines) 🤝

Tunakaribisha michango kutoka kwa jamii ya ma-developer wote wa Kenya na Afrika Mashariki!

### Sheria Kuu za Uchangiaji:
1. **Zingatia Kanuni ya "Bila Deep Translation":**
   Usijaribu kutafsiri maneno ya standard ya Python kuwa Kiswahili kigumu. Tumia lugha ya kawaida inayofahamika kwenye code-reviews za maofisini.
2. **Code Snippets Lazima Ziwe Halisi:**
   Code zote za mifano lazima zifanye kazi kwenye Python 3.10+ bila errors.
3. **Mifano ya Kiuhalisia ya Kenya:**
   Mifano ya bidhaa, malipo (kama M-Pesa), na maisha ya kawaida ya Afrika Mashariki inahimizwa ili kusaidia uelewa wa haraka.

### Jinsi ya Kufungua Pull Request:
1. Fork repository hii.
2. Tengeneza branch mpya ya feature yako: `git checkout -b feature/mada-mpya`.
3. Fanya mabadiliko na u-commit: `git commit -m "docs: ongeza mfano wa background tasks"`.
4. Push kwa branch yako: `git push origin feature/mada-mpya`.
5. Fungua Pull Request (PR).
